# Report Sheets Reference

> Detailed guide to every sheet in `backtest_report.xlsx`, generated by `reporting/backtest_report.py → generate_backtest_report()`.

---

## Overview

The backtest report consolidates all analytics, charts, and raw data into a single Excel workbook. Up to **17 sheets** are produced — some are conditional on available data.

| # | Sheet | Type | Conditional? |
|---|-------|------|-------------|
| 1 | `portfolio_metrics` | Analytics | No |
| 2 | `benchmark_metrics` | Analytics | Yes — requires index data |
| 3 | `periodic_returns` | Analytics | No |
| 4 | `rolling_returns` | Analytics | No |
| 5 | `calendar_returns` | Analytics | Yes — needs ≥1 calendar year |
| 6 | `up_down_months` | Analytics | No |
| 7 | `trailing_returns` | Analytics | No |
| 8 | `quarter_analysis` | Analytics | No |
| 9 | `quarterly_alpha` | Analytics | Yes — requires index + trades |
| 10 | `crisis_regimes` | Analytics | Yes — requires date overlap |
| 11 | `market_regimes` | Analytics | Yes — requires date overlap |
| 12 | `stock_counts_by_mcap` | Analytics | Yes — requires mcap categories |
| 13 | `charts` | Visualizations | No (images embedded) |
| 14 | `trade_results` | Raw data | No |
| 15 | `daily_portfolio_values` | Raw data | No |
| 16 | `portfolio_vs_index` | Raw data | Yes — requires index data |
| 17 | `data_quality_issues` | Raw data | Yes — only if issues found |

---

## Analytics Sheets

### 1. `portfolio_metrics`

Standalone portfolio performance summary (no benchmark needed).

| Column | Description |
|--------|-------------|
| `start_date` | First date in the backtest |
| `end_date` | Last date in the backtest |
| `trading_days` | Total number of trading days |
| `years` | Duration in years |
| `initial_value` | Starting portfolio value (₹) |
| `final_value` | Ending portfolio value (₹) |
| `total_return_pct` | Total cumulative return (%) |
| `cagr_pct` | Compound Annual Growth Rate (%) |
| `volatility_pct` | Annualized volatility (%) |
| `sharpe_ratio` | Sharpe ratio (risk-free rate = 6.5%) |
| `sortino_ratio` | Sortino ratio (downside deviation only) |
| `max_drawdown_pct` | Maximum peak-to-trough drawdown (%) |
| `calmar_ratio` | CAGR / Max Drawdown |
| `var_95_pct` | 95% Value at Risk — daily (%) |
| `best_day_pct` | Best single-day return (%) |
| `worst_day_pct` | Worst single-day return (%) |
| `positive_days_pct` | Percentage of days with positive returns |

---

### 2. `benchmark_metrics`

Relative performance vs index. Only present when index data is provided.

| Column | Description |
|--------|-------------|
| `portfolio_return_pct` | Portfolio total return (%) |
| `index_return_pct` | Index total return (%) |
| `alpha_pct` | Excess return over benchmark (%) |
| `beta` | Portfolio beta to index |
| `tracking_error_pct` | Active risk — standard deviation of excess returns (%) |
| `information_ratio` | Alpha / Tracking Error |
| `up_capture_pct` | Up-market capture ratio (%) |
| `down_capture_pct` | Down-market capture ratio (%) |
| `correlation` | Portfolio-index return correlation |
| `outperformance_days_pct` | % of days portfolio outperformed index |

---

### 3. `periodic_returns`

Since-inception and optional sub-period performance statistics. Multiple sections are stacked vertically (separated by gaps) — first the since-inception block, then one block per sub-period defined in `report_sub_periods`.

| Column | Description |
|--------|-------------|
| Index | Strategy name (Portfolio, Benchmark) |
| `G-Rs100` | Growth of ₹100 |
| `AReturns` | Annualized return |
| `ARisk` | Annualized risk (volatility) |
| `Sharpe` | Sharpe ratio |
| `DDown` | Maximum drawdown |
| `Sortino` | Sortino ratio |
| `Skewness` | Return distribution skewness |
| `Kurtosis` | Return distribution kurtosis |
| `%Up_Periods` | Percentage of positive months |
| `%Down_Periods` | Percentage of negative months |

---

### 4. `rolling_returns`

Distribution statistics for rolling 1-year, 3-year, and 5-year annualized returns. Up to three sections stacked vertically.

| Column | Description |
|--------|-------------|
| Index | Strategy name |
| `count` | Number of rolling windows |
| `min` | Minimum rolling return |
| `25%` | 25th percentile |
| `50%` | Median |
| `75%` | 75th percentile |
| `max` | Maximum rolling return |
| `<0%P` | Probability of negative rolling return |
| `0-10%P` | Probability of 0-10% rolling return |
| `10-20%P` | Probability of 10-20% rolling return |
| `>20%P` | Probability of >20% rolling return |

---

### 5. `calendar_returns`

Annual returns by calendar year.

| Column | Description |
|--------|-------------|
| `Calendar_Year` | Year (index) |
| Per-strategy columns | Calendar year return (%) for each strategy |

---

### 6. `up_down_months`

Count of positive and negative monthly returns.

| Row | Description |
|-----|-------------|
| `Up_Months` | Number of months with positive returns |
| `Down_Months` | Number of months with negative returns |

---

### 7. `trailing_returns`

Point-in-time trailing returns from the most recent date in the backtest.

| Row | Description |
|-----|-------------|
| `1-m` | 1-month trailing return |
| `3-m` | 3-month trailing return |
| `6-m` | 6-month trailing return |
| `1-year` | 1-year trailing return |
| `3-years` | 3-year annualized trailing return |
| `5-years` | 5-year annualized trailing return |
| `10-years` | 10-year annualized trailing return |

---

### 8. `quarter_analysis`

Per-quarter trade breakdown by category.

| Column | Description |
|--------|-------------|
| `quarter` | Quarter code (YYYYMM) |
| `total_stocks` | Total stocks traded |
| `{cat}_count` | Number of stocks per category (dynamic column names) |
| `avg_holding_period` | Average holding period in days |
| `TP_count` | Number of trades exiting at take profit |
| `SL_count` | Number of trades exiting at stop loss |
| `time_exit_count` | Number of trades exiting at quarter end |
| `avg_holding_period_SL` | Average holding period for SL exits |
| `avg_holding_period_TP` | Average holding period for TP exits |
| `{cat}_avg_hp` | Average holding period per category |
| `{cat}_return` | Average return per category |
| `portfolio_return` | Aggregate portfolio return for the quarter |

---

### 9. `quarterly_alpha`

Per-quarter outperformance vs benchmark with summary statistics appended at the bottom.

| Column | Description |
|--------|-------------|
| `Quarter` | Quarter code or summary label |
| `Portfolio_Return` | Portfolio return for the quarter (%) |
| `Benchmark_Return` | Benchmark return for the quarter (%) |
| `Outperformance` | Alpha = Portfolio − Benchmark (%) |

Summary rows at the bottom include: Average, Median, Std Dev, Min, Max, % Outperforming.

---

### 10. `crisis_regimes`

Portfolio and benchmark returns during historical crisis periods.

Defined crisis windows: **GFC**, **Taper Tantrum**, **Yuan Devaluation**, **Covid Crash**, **Russia-Ukraine War**.

| Column | Description |
|--------|-------------|
| `Crisis_Regime` | Crisis name (index) |
| `Start_Date` | Window start |
| `End_Date` | Window end |
| Per-strategy columns | Return during the crisis window (%) |

Only crisis periods overlapping with your backtest date range are shown.

---

### 11. `market_regimes`

Performance during bull, bear, and recovery markets.

Defined as 6 bear phases, 4 bull phases, and 4 recovery phases from 2008–2025 (sourced from `config/regime_dates.yaml`).

| Column | Description |
|--------|-------------|
| `Market_Regime` | Regime label (index) |
| `Start_Date` | Window start |
| `End_Date` | Window end |
| Per-strategy columns | Return during the regime (%) |

---

### 12. `stock_counts_by_mcap`

Quarterly breakdown of stocks by market capitalization. Only present when mcap labels exist.

| Column | Description |
|--------|-------------|
| `quarter` | Quarter code |
| `total_stocks` | Total stocks in the quarter |
| `largecap` | Number of large-cap stocks |
| `midcap` | Number of mid-cap stocks |
| `smallcap` | Number of small-cap stocks |

An **Average** row is appended at the bottom.

---

## Charts Sheet

### 13. `charts`

No tabular data — contains embedded PNG charts:

| Chart | Description | Conditional? |
|-------|-------------|-------------|
| Portfolio vs Index | Equity curves overlaid | Yes — needs index data |
| Growth of Wealth | Growth of ₹100 invested | No |
| Daily Drawdown | Drawdown profile over time | No |
| Monthly Returns Heatmap | Month × Year heatmap | No |
| Calendar Year Returns | Year-over-year bar chart | Yes — needs ≥1 year |
| Correlation Matrix | Strategy correlation heatmap | No |
| Distribution of Monthly Returns | Histogram of monthly returns | No |
| Box-Whisker Plot | Return distribution box plot | No |

---

## Raw Data Sheets

### 14. `trade_results`

Complete trade-level output from `simulate_trades()`. One row per stock-quarter.

Key columns: `quarter`, `co_name`, `cat`, `entry_price`, `exit_price`, `exit_date`, `exit_type`, `stock_return`, `holding_period`, `TP_triggered`, `SL_triggered`, `tp_pct`, `sl_pct`, `tp_mode`, `sl_mode`, `cat_weight` / `stock_weight`.

---

### 15. `daily_portfolio_values`

Daily time series of aggregate portfolio value.

| Column | Description |
|--------|-------------|
| `date` | Trading date |
| `portfolio_value` | Portfolio NAV on that date (₹) |
| `quarter` | Active quarter code |

---

### 16. `portfolio_vs_index`

Daily comparison of portfolio and index performance. Only present when index data is provided.

| Column | Description |
|--------|-------------|
| `date` | Trading date |
| `pf_value` | Portfolio value (₹) |
| `pf_return` | Portfolio daily return |
| `index_fund_value` | Index fund value (₹) |
| `index_return` | Index daily return |
| `alpha` | Daily excess return |

---

### 17. `data_quality_issues`

Log of data anomalies detected during validation. Only present if issues were found.
